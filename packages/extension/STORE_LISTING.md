## 2. Detailed Description (Copy & Paste into Chrome Web Store)

```markdown
Transform any text into camelCase, snake_case, PascalCase, kebab-case, Title Case, and 25+ formats instantly — right from your browser toolbar or right-click context menu!

Whether you are writing code, crafting database columns, creating clean URL slugs, or editing article titles, FormatCase eliminates tedious manual editing and regex tricks with instant, 100% in-browser transformation.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 KEY FEATURES AT A GLANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ Right-Click Context Menu Transformation
Highlight any text on any website, right-click, and select FormatCase to convert and copy directly to your clipboard in 1 click!

🛠️ Compact Popup Workbench (Click toolbar icon)
Type or paste words, sentences, or code identifiers into the popup to see live previews across all 25+ case formats simultaneously.

🧠 Smart Unicode Acronym Tokenizer
Unlike naive converters that ruin abbreviations, FormatCase's intelligent tokenizer understands acronym boundaries:
• "parseHTTPResponseJSON" ➔ "parse_http_response_json"
• "XMLHttpRequest" ➔ "xml_http_request"

🔒 100% Client-Side Privacy (Zero Data Leaves Your Device)
FormatCase runs entirely inside your browser’s local memory. No analytics tracking, no external API calls, and zero keystroke logging. Your code and confidential strings remain strictly private.

📋 One-Click Copy & Paste Shortcuts
Instant copy buttons with celebratory visual feedback. Includes a "Paste Clipboard" shortcut and real-time character, word, and line count metrics.

🔍 Instant Format Search & Category Filtering
Quickly find the exact casing convention you need using the search bar or filter by Developer, Natural Language, or Web Utility formats.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📚 25+ SUPPORTED FORMATS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

👨‍💻 Developer & Programming Conventions:
• camelCase ➔ helloWorld (JavaScript, TypeScript, Swift, Go)
• PascalCase / StudlyCaps ➔ HelloWorld (React components, classes, C#)
• snake_case ➔ hello_world (Python, Rust, database columns)
• SCREAMING_SNAKE_CASE ➔ HELLO_WORLD (Environment variables, constants)
• kebab-case / lower-kebab-case ➔ hello-world (CSS classes, HTML attributes)
• UPPER-KEBAB-CASE / COBOL-CASE ➔ HELLO-WORLD
• Train-Case / Header-Case ➔ Hello-World (HTTP headers)
• dot.case ➔ hello.world (Configuration files, property paths)
• path/case / Slash Case ➔ hello/world (File systems, routing keys)
• Hash Case ➔ hello#world (Tags, anchors)
• Pascal_Snake_Case ➔ Hello_World
• camel_Snake_Case ➔ hello_World
• BiCapitalization ➔ iPhone, eBay (Product branding)
• Hungarian Notation ➔ strName, iCount (Typed variables)
• mACRO_CASE ➔ hello_WORLD
• Flatcase ➔ helloworld (Package names)
• Reverse Pascal Case ➔ hELLOWORLD

✍️ Natural Language & Editorial Styles:
• Title Case ➔ The Quick Brown Fox Jumps (Preserves minor words like in, the, on)
• Sentence case ➔ Hello world example
• UPPERCASE ➔ HELLO WORLD
• lowercase ➔ hello world
• Capitalized Case ➔ Hello World Example
• aLtErNaTiNg cAsE ➔ hElLo wOrLd (Meme & casual text)
• InVeRsE cAsE ➔ Flips uppercase and lowercase

🔗 Web Utility:
• slugify ➔ clean-url-safe-slug (Strips accents, diacritics & special characters)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Method 1: Context Menu (Quickest)
1. Select any text on any webpage.
2. Right-click and hover over "FormatCase".
3. Choose your desired format (e.g. "to camelCase").
4. The converted text is instantly copied to your clipboard!

Method 2: Popup Workbench
1. Click the FormatCase extension icon in your Chrome toolbar.
2. Type or paste your string into the workbench.
3. Browse live converted outputs and click "Copy" next to your target format.
4. Need the full web suite? Click "Web App" to open https://formatcase.netlify.app/.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🛡️ PERMISSIONS EXPLAINED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
We believe in total transparency. FormatCase requires only the absolute minimum permissions needed to function:
• "contextMenus": Adds the right-click casing options when selecting text.
• "clipboardWrite": Allows copying formatted strings directly to your clipboard.
• "activeTab" & "scripting": Pastes converted text from right-click actions into active tab clipboard.
• "storage": Saves your UI preferences and favorite casing formats locally.
```
