FormatCase Official Policy

Privacy Policy

Last updated: September 2026 • Applies to FormatCase Web & Chrome Extension

1. Overview & Single Purpose

FormatCase ("we", "our", or "the extension") is a developer productivity utility designed to transform text strings between 25+ casing conventions (such as camelCase, snake_case, PascalCase, kebab-case, and Title Case).

We are firmly committed to user privacy. We do not collect, store, transmit, process, or sell any personal data, keystrokes, or text inputs.

2. Zero Data Collection Guarantee

FormatCase is built on a 100% Client-Side Architecture:

  • No Network Transmission: The text you format never leaves your web browser. All transformations are performed strictly in local memory using our in-browser algorithm.
  • No Analytics or Tracking: The Chrome extension contains zero tracking pixels, telemetry, or third-party analytical scripts.
  • No Personal Identifiers: We do not ask for or collect names, email addresses, IP addresses, browsing histories, or location data.
  • No Keystroke Logging: FormatCase does not monitor or log keyboard activities.

3. Chrome Extension Permissions Justification

In accordance with Google Chrome Web Store Developer Policies, here is why each permission is required:

  • activeTab & scripting: Used solely to read user-selected text and write the formatted result into your clipboard when you trigger a right-click context menu transformation.
  • clipboardWrite: Enables writing the converted text string directly to your clipboard upon clicking "Copy" or using context menus.
  • contextMenus: Allows registering the "FormatCase" sub-menu options when you highlight text on any web page.
  • storage: Used strictly on your local machine to save your UI preferences (such as favorite casing formats and active filters). No data is synced to external servers.

4. Third-Party Services

The FormatCase Chrome Extension operates completely offline and does not communicate with any third-party APIs or remote servers.
